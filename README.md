# 🛡️ EarlyShield — AI-Based Landslide Early Warning System

**SIH 2026 | BWU Team | North East India**

EarlyShield is an AI-powered, real-time landslide prediction and early warning platform specifically built for North East India.

## 🌐 Live Demo
Open `index.html` in any browser — no server needed.

## ✨ Features
- 🗺️ **GIS Risk Heatmap** — Interactive map with real-time risk zones across 162 NER districts
- 📊 **AI Dashboard** — Live stats: sensors, rainfall, NDRF teams, SMS alerts
- 🚨 **Alert Management** — AI-generated alerts ranked by urgency, one-click broadcast
- 🧠 **Analytics Engine** — RandomForest, LSTM, XGBoost models (94% accuracy)
- 🌧️ **Weather Integration** — Live IMD weather feeds
- 📡 **IoT Sensor Network** — 48 sensor nodes (soil moisture, rainfall, slope tilt)
- 📋 **Citizen Field Reports** — Geo-tagged photo submissions with CNN image analysis
- 🚛 **Response Coordination** — NDRF team dispatch dashboard
- 🌐 **8 Regional Languages** — Assamese, Meitei, Bodo, Khasi, Mizo, Bengali, Nepali, English
- 📶 **Offline PWA Support** — Works in low/no connectivity areas

## 🏗️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Maps:** Leaflet.js + OpenStreetMap
- **AI Models:** RandomForest, XGBoost, LSTM, CNN, K-Means (simulated in frontend)
- **PWA:** Service Worker with offline caching
